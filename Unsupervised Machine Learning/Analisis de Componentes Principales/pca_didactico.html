Analisis de Componentes Principales

El PCA es una herramienta de reduccion de dimensionalidad que transforma un conjunto de variables correlacionadas en un conjunto menor de variables ortogonales — los componentes principales — que capturan la mayor parte de la informacion original.

Reduccion de dimension Algebra lineal sklearn · numpy No supervisado

Por que usar PCA

Cuando un conjunto de datos contiene muchas variables, no todas contribuyen de forma independiente. Algunas estan correlacionadas, son redundantes o aportan solo ruido. Esto genera dos problemas principales:

Maldicion de la dimensionalidad

El volumen del espacio crece exponencialmente con el numero de dimensiones. Los datos se vuelven escasos y los algoritmos basados en distancias pierden efectividad.

Multicolinealidad

Variables altamente correlacionadas aportan informacion redundante e inestabilizan los coeficientes de los modelos. PCA genera componentes ortogonales, eliminando la correlacion.

El PCA resuelve estos problemas encontrando un nuevo sistema de ejes — los componentes principales — orientados en las direcciones de maxima varianza de los datos.

Idea central: si tienes n individuos con p variables, PCA encuentra un numero menor de factores subyacentes (k < p) que explican aproximadamente la misma informacion que las p variables originales. Cada individuo que antes requeria p valores ahora se describe con solo k valores.

La matematica del PCA

Matriz de covarianza

El PCA opera sobre la matriz de covarianza, que cuantifica como varian conjuntamente cada par de variables. Un valor positivo indica que las variables tienden a moverse juntas; negativo, que se mueven en sentidos opuestos.

$$\text{Cov}(X,Y) = \frac{\displaystyle\sum_{i=1}^{n}(X_i - \mu_X)(Y_i - \mu_Y)}{n-1}$$

Eigenvectores y eigenvalues

Dado un vector especial v y una matriz cuadrada A, si al multiplicar A por v el resultado es simplemente v escalado por un numero lambda, entonces v es un eigenvector de A y lambda es su eigenvalue:

$$A \cdot \mathbf{v} = \lambda \cdot \mathbf{v}$$
Eigenvectores — Direccion

Apuntan en las direcciones donde los datos exhiben mayor dispersion. En PCA, cada eigenvector de la matriz de covarianza define un componente principal. Son siempre perpendiculares (ortogonales) entre si.

Eigenvalues — Magnitud

Cuantifican cuanta varianza captura cada componente. Un eigenvalue mas alto indica mas informacion en esa direccion. Los componentes se ordenan de mayor a menor eigenvalue.

Propiedades clave de los eigenvectores:
Solo existen para matrices cuadradas. Para una matriz n x n hay como maximo n eigenvectores. Al escalar un eigenvector (multiplicarlo por una constante), sigue siendo eigenvector de la misma matriz. Todos son mutuamente ortogonales.

Los loadings

Cada componente principal Zi es una combinacion lineal de las variables originales. Los coeficientes de esa combinacion se llaman loadings (pesos):

$$Z_1 = \phi_{11}X_1 + \phi_{21}X_2 + \ldots + \phi_{p1}X_p$$

Con la restriccion de normalizacion:

$$\sum_{j=1}^{p} \phi_{j1}^2 = 1$$

Los loadings indican la importancia de cada variable original en cada componente. Valores grandes (en valor absoluto) significan que esa variable contribuye mucho a esa componente.

La suma de cargas al cuadrado es siempre 1

Esta restriccion no es arbitraria: garantiza que cada componente sea un vector unitario (longitud 1) en el espacio de las variables originales. Es equivalente a decir que el eigenvector esta normalizado.

Por que importa la normalizacion: si no se impusiera esta restriccion, se podria escalar el vector de loadings por cualquier constante y obtener infinitas soluciones equivalentes. Al fijar la longitud a 1, la solucion es unica (salvo el signo) y los loadings son comparables entre si y entre distintos componentes.

Verificacion con los loadings reales del dataset USArrests para PC1:

$$\phi_{11}^2 + \phi_{21}^2 + \phi_{31}^2 + \phi_{41}^2 = 1$$
$$0{.}5359^2 + 0{.}5832^2 + 0{.}2782^2 + 0{.}5434^2 = 0{.}2872 + 0{.}3401 + 0{.}0774 + 0{.}2953 = 1$$
Interpretacion geometrica: los loadings son las cosenos directores del componente respecto a cada eje original. Al estar normalizados, el cuadrado de cada loading representa la fraccion de la longitud del vector que apunta en esa direccion. La suma de esas fracciones debe ser necesariamente 1.

Ortogonalidad entre componentes principales

Una propiedad fundamental del PCA es que todos los componentes principales son ortogonales entre si, es decir, sus vectores de loadings son perpendiculares. En terminos algebraicos, el producto punto entre dos componentes cualesquiera es cero:

$$\phi_k \cdot \phi_m = \sum_{j=1}^{p} \phi_{jk}\,\phi_{jm} = 0 \quad \text{para } k \neq m$$

La consecuencia practica mas importante de la ortogonalidad es que los scores de los componentes no estan correlacionados. Esto se puede verificar directamente calculando la matriz de correlaciones entre los scores:

# Verificar ortogonalidad: correlacion entre componentes
corr_matrix = scores_df.corr().round(1).abs()
print(corr_matrix)

Matriz de correlaciones entre componentes principales

El resultado es una matriz identidad: la diagonal vale 1 (cada componente se correlaciona perfectamente consigo mismo) y todos los valores fuera de la diagonal son 0 (ningun par de componentes comparte informacion).

Sin ortogonalidad (variables originales)

Las variables originales suelen estar correlacionadas. Por ejemplo, en USArrests, Murder y Assault tienen correlacion alta: un estado con muchos asesinatos tiende a tener muchos asaltos. Esto genera informacion redundante.

Con ortogonalidad (componentes PCA)

Los componentes PCA son por construccion incorrelacionados. PC1 captura el nivel general de criminalidad; PC2 captura urbanizacion. Son dimensiones completamente independientes: saber el valor de PC1 no dice nada sobre PC2.

Por que la ortogonalidad es valiosa en Machine Learning: cuando se usan los scores de PCA como predictores de un modelo supervisado, la ausencia de correlacion entre ellos elimina la multicolinealidad, estabiliza los coeficientes estimados y facilita la interpretacion del modelo resultante.

Interpretacion geometrica

Imaginemos datos bivariados (dos variables X1 y X2) como una nube de puntos. Los componentes principales son los nuevos ejes del sistema de coordenadas que mejor describe la variabilidad de esa nube.

La flecha roja indica el primer componente principal (PC1); la verde indica PC2. Ambas son perpendiculares. Ajusta la correlacion para ver como cambian las direcciones.

Cada observacion que antes tenia coordenadas en el espacio original (X1, X2) ahora tiene nuevas coordenadas en el espacio de los componentes principales. Esas nuevas coordenadas se llaman scores o proyecciones.

Proyecciones (scores): son la posicion de cada observacion en el nuevo sistema de ejes definido por los componentes principales. La proyeccion sobre PC1 es el valor de la primera componente para esa observacion.

El algoritmo paso a paso

  1. Estandarizar los datos. Restar la media de cada variable y dividir por su desviacion estandar. Esto garantiza que todas las variables tengan media 0 y desviacion 1. Si no se estandariza, las variables con mayor escala dominaran los componentes.
  2. Calcular la matriz de covarianza. Con los datos estandarizados, construir la matriz de covarianza (o correlacion). Esta matriz es cuadrada (p x p) y simetrica.
  3. Descomposicion en eigenvectores y eigenvalues. Resolver el problema de autovalores de la matriz de covarianza. Esto puede hacerse via SVD (Descomposicion en Valores Singulares), que es el metodo que usa sklearn por defecto.
  4. Ordenar por eigenvalue descendente. El eigenvector con mayor eigenvalue es PC1 (captura mas varianza), el siguiente es PC2, y asi sucesivamente.
  5. Proyectar los datos. Multiplicar los datos estandarizados por la matriz de eigenvectores para obtener los scores (coordenadas en el espacio PCA).
Sobre la reproducibilidad: el PCA es deterministico — siempre produce los mismos componentes. La unica diferencia posible es el signo de los loadings (invertir todos los signos de un componente no cambia la informacion que contiene).

Varianza explicada y seleccion de componentes

La varianza total del conjunto de datos (con variables normalizadas) es:

$$VT = \sum_{j=1}^{p} \frac{1}{n} \sum_{i=1}^{n} x_{ij}^2$$

La proporcion de varianza explicada por el componente m es:

$$\text{PVE}_m = \frac{\displaystyle\sum_{i=1}^{n}\!\left(\sum_{j=1}^{p} \phi_{jm}\, x_{ij}\right)^{\!2}}{\displaystyle\sum_{j=1}^{p}\sum_{i=1}^{n} x_{ij}^2}$$

El sumatorio de todas las PVE es siempre 1 (si se calculan todos los componentes posibles).

Scree plot — Seleccion optima de componentes

No existe un criterio unico para elegir cuantos componentes conservar. La estrategia mas comun es el scree plot: graficar la proporcion de varianza acumulada y buscar el punto donde el incremento deja de ser sustancial.

Proyecciones: utilidad e interpretacion

Una vez ajustado el modelo PCA, cada observacion pasa de tener coordenadas en el espacio original (p variables) a tener coordenadas en el espacio de los componentes principales. Estas nuevas coordenadas se denominan scores o proyecciones y son el resultado practico mas util del PCA.

Que representa cada score: el score de un estado en PC1 indica su posicion a lo largo del eje de "criminalidad general". Un score alto en PC1 significa estado con alta criminalidad; un score alto en PC2 significa estado muy urbanizado con baja tasa de homicidio. Cada componente tiene una interpretacion semantica propia derivada de sus loadings.

Como se calculan — producto matricial

La proyeccion es simplemente el producto punto entre los datos estandarizados y los eigenvectores. Hay dos formas equivalentes de obtenerla:

# Forma 1 — usando .transform() del pipeline (recomendado)
proyecciones = pca_pipe.transform(X=datos)
proyecciones = pd.DataFrame(
proyecciones,
columns = ['PC1', 'PC2', 'PC3', 'PC4'],
index = datos.index
)
proyecciones.head()
# Forma 2 — producto matricial manual (equivalente exacto)
# modelo_pca.components_ → shape (4x4) los eigenvectores
# scale(datos).T → shape (4x50) datos estandarizados traspuestos
# resultado → shape (4x50) → transponer → (50x4)
proyecciones = np.dot(modelo_pca.components_, scale(datos).T)
proyecciones = pd.DataFrame(proyecciones, index = ['PC1', 'PC2', 'PC3', 'PC4'])
proyecciones = proyecciones.transpose().set_index(datos.index)
proyecciones.head()

Ambas formas producen el mismo resultado. El np.dot explicita que la proyeccion es una multiplicacion de la matriz de componentes (4x4) por la transpuesta de los datos escalados (4x50), dando una matriz (4x50) que al transponerse queda en la forma habitual (50x4) — una fila por estado, una columna por componente.

import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
import plotly.express as px

# Escalar + PCA 2 componentes

proj = pca.transform(X_sc)

# DataFrame de proyecciones + region geografica

# Scatter interactivo con Plotly
fig = px.scatter(

)
display(HTML(fig.to_html(full_html=False, include_plotlyjs=True)))

Criterios para seleccionar el numero de componentes

Una de las decisiones mas importantes al aplicar PCA es determinar cuantos componentes conservar. No existe un criterio unico y universalmente correcto: la eleccion depende del contexto, el objetivo del analisis y el nivel de tolerancia a la perdida de informacion.

1. Regla de la varianza acumulada

La mas usada en la practica. Se fija un umbral de varianza acumulada y se selecciona el minimo numero de componentes que lo superan. El umbral varia segun el dominio:

2. Regla de Kaiser (λ > 1)

Retener solo los componentes cuyo eigenvalue supere 1. La justificacion es que un componente debe explicar mas varianza que una sola variable original estandarizada (que tiene varianza = 1). Tiende a seleccionar pocos componentes.

3. Scree plot — el "codo"

Graficar los eigenvalues en orden descendente y buscar el punto donde la curva pasa de caer bruscamente a estabilizarse. Los componentes antes del codo se retienen; los que caen en la zona plana se descartan.

4. Bootstrap / Permutacion

Comparar los eigenvalues reales con los obtenidos al permutar aleatoriamente los datos. Se retienen los componentes cuyo eigenvalue real supera al esperado por azar. Es el criterio mas riguroso, usado en publicaciones cientificas.

Criterio de Kaiser — implementacion paso a paso

El criterio de Kaiser aplicado sobre un objeto PCA ya ajustado de sklearn se implementa de la siguiente forma. El atributo explained_variance_ contiene los eigenvalues reales (no la proporcion de varianza, sino los valores propios en escala original):

# Assuming pca is already fitted PCA object from sklearn
eigenvalues = pca.explained_variance_

# Applying Kaiser Criterion
kaiser_criterion = eigenvalues > 1

# Get the number of components that satisfy the Kaiser Criterion
n_components_kaiser = sum(kaiser_criterion)

# Print the components that satisfy the criterion
print(f"Number of components with eigenvalue > 1: {n_components_kaiser}")
important_components = np.arange(1, n_components_kaiser + 1)
print(f"Important components according to Kaiser Criterion: {important_components}")

# Optionally, if you want to see which specific components satisfy the criterion
for i, (ev, satisfy) in enumerate(zip(eigenvalues, kaiser_criterion), start=1):
if satisfy:
print(f"Component {i} with eigenvalue: {ev}")

Nota sobre explained_variance_ vs explained_variance_ratio_:
— pca.explained_variance_: eigenvalues en escala absoluta (los lambda). Se usan para Kaiser.
— pca.explained_variance_ratio_: proporcion de varianza explicada (entre 0 y 1). Se usan para el umbral de varianza acumulada.
— Ambos estan ordenados de mayor a menor por sklearn automaticamente.

PCA combinado con regresion

Una de las aplicaciones mas poderosas del PCA en Machine Learning es su uso como etapa de preprocesado antes de ajustar un modelo de regresion. Esta combinacion se conoce como Regresion de Componentes Principales (PCR — Principal Component Regression).

El problema que resuelve

La regresion lineal ordinaria sufre cuando los predictores estan altamente correlacionados entre si (multicolinealidad). En ese escenario:

Problemas sin PCA

Los coeficientes estimados son inestables: pequenos cambios en los datos producen grandes cambios en los coeficientes. Los errores estandar se inflan, las pruebas t pierden potencia y la interpretacion se vuelve ambigua. Ademas, con p > n el sistema es indeterminado.

Soluciones con PCA

Al proyectar los datos en el espacio PCA antes de ajustar la regresion, los predictores del modelo (los scores) son por construccion incorrelacionados. Los coeficientes son estables, interpretables y el modelo generaliza mejor a datos nuevos.

El flujo PCR paso a paso

  1. Estandarizar X. Escalar todas las variables predictoras a media 0 y desviacion 1 usando StandardScaler.
  2. Ajustar PCA sobre X escalado. Calcular los k componentes principales que capturan el umbral de varianza deseado.
  3. Transformar X en scores. Proyectar los datos originales al espacio PCA. Se obtiene una matriz de dimensiones (n, k) con k << p.
  4. Ajustar la regresion sobre los scores. Usar los k scores como predictores de la variable respuesta Y. Al ser ortogonales, la regresion es numericamente estable.
  5. Interpretar y predecir. Para nuevos datos, primero transformarlos con el PCA entrenado, luego aplicar el modelo de regresion.

Formula del modelo PCR

$$\hat{Y} = \beta_0 + \beta_1 Z_1 + \beta_2 Z_2 + \ldots + \beta_k Z_k$$

Donde $Z_1, Z_2, \ldots, Z_k$ son los scores de los k componentes principales retenidos, y los $\beta_j$ son los coeficientes estimados por minimos cuadrados ordinarios sobre ese espacio ortogonal.

Diferencia clave con Ridge y Lasso: PCR descarta completamente los componentes de baja varianza (los elimina del modelo). Ridge y Lasso los encogen hacia cero pero los mantienen. PCR es la opcion mas interpretable cuando los componentes tienen un significado semantico claro, como en el ejemplo de USArrests donde PC1 = criminalidad y PC2 = urbanizacion.

Implementacion completa en sklearn

from sklearn.decomposition import PCA
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import cross_val_score

# ── PCR: Regresion lineal sobre componentes principales ──────
pcr_pipe = Pipeline([
('scaler', StandardScaler()),
('pca', PCA(n_components=0.85)), # retener 85% varianza
('reg', LinearRegression())
])

# Ajustar y evaluar con validacion cruzada (5 folds)
scores = cross_val_score(
pcr_pipe, X, y,
cv=5, scoring='r2'
)
print(f"R² medio (CV): {scores.mean():.3f} ± {scores.std():.3f}")

# ── Seleccionar k optimo por cross-validation ────────────────
resultados = []
for k in range(1, X.shape[1] + 1):
pipe_k = Pipeline([
('sc', StandardScaler()),
('pca', PCA(n_components=k)),
('lr', LinearRegression())
])
r2 = cross_val_score(pipe_k, X, y, cv=5, scoring='r2').mean()
resultados.append({'k': k, 'R2_CV': round(r2, 4)})

Limitacion importante de PCR: los componentes se calculan maximizando la varianza de X, sin considerar Y en absoluto. Puede ocurrir que el componente que mas varianza captura en X sea el menos relevante para predecir Y. En esos casos, la Regresion de Minimos Cuadrados Parciales (PLS) es superior porque calcula componentes que maximizan la covarianza entre X e Y simultaneamente.

La clase sklearn.decomposition.PCA implementa todas las funcionalidades necesarias. El flujo estandar combina un StandardScaler y PCA dentro de un pipeline.

Flujo completo — Dataset USArrests

import numpy as np
import pandas as pd
from sklearn.decomposition import PCA
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

# Cargar datos
datos = pd.read_csv('USArrests.csv').set_index('rownames')

# Pipeline: estandarizacion + PCA
pca_pipe = make_pipeline(StandardScaler(), PCA())
pca_pipe.fit(datos)

# Extraer el modelo PCA del pipeline
modelo_pca = pca_pipe.named_steps['pca']

# Loadings (eigenvectores) — shape (n_components, n_features)
componentes = pd.DataFrame(
data=modelo_pca.components_,
columns=datos.columns,
index=['PC1', 'PC2', 'PC3', 'PC4']
)

# Varianza explicada por componente
modelo_pca.explained_variance_ratio_
# array([0.62006039, 0.24744129, 0.0891408 , 0.04335752])

# Varianza acumulada
modelo_pca.explained_variance_ratio_.cumsum()
# array([0.62006039, 0.86750168, 0.95664248, 1. ])

# Proyectar (obtener scores)
scores = pca_pipe.transform(datos)
scores_df = pd.DataFrame(scores, index=datos.index,
columns=['PC1','PC2','PC3','PC4'])

Verificar ortogonalidad

# La correlacion entre componentes debe ser cero
scores_df.corr().round(1).abs()
# PC1 PC2 PC3 PC4 # PC1 1.0 0.0 0.0 0.0 # PC2 0.0 1.0 0.0 0.0 # PC3 0.0 0.0 1.0 0.0 # PC4 0.0 0.0 0.0 1.0
Usos principales de los scores transformados: visualizacion 2D/3D (PC1 vs PC2), entrada a modelos supervisados con menor numero de predictores, deteccion de outliers, y clustering en espacio reducido.

PCA como preprocesado para modelos supervisados

from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

# Pipeline completo: escalar -> reducir -> clasificar
pipeline_ml = Pipeline([
('scaler', StandardScaler()),
('pca', PCA(n_components=0.95)), # retener 95% de varianza
('clf', LogisticRegression())
])

pipeline_ml.fit(X_train, y_train)
pipeline_ml.score(X_test, y_test)
Nota tecnica: PCA(n_components=0.95) selecciona automaticamente el numero minimo de componentes necesarios para explicar al menos el 95% de la varianza. Esta es una forma practica de automatizar la seleccion del numero optimo de componentes.
