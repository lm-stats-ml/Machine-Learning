01 — Concepto

Que es la Regresion Lineal Multiple?

El modelo de regresion lineal parte del concepto de funcion economica. Lo ilustramos con una funcion de demanda de cerveza: ¿como cambia la cantidad demandada cuando varían el precio y el ingreso?

Del concepto de funcion al modelo

La teoria economica nos dice que la cantidad demandada q depende de un conjunto de variables. En forma general:

q = f(pb, m)

Donde pb es el precio de la cerveza y m es el ingreso del consumidor. Pero esta funcion no especifica si la relacion es directa o inversa. Para eso usamos derivadas parciales:

∂q / ∂pb < 0
Ley de demanda
∂q / ∂m > 0
Bien normal

La teoria predice que a mayor precio, la cantidad cae; y a mayor ingreso, la cantidad sube. El modelo nos permite verificar y cuantificar estos efectos con datos reales.

Ecuacion 1 — El modelo de regresion

Yi = β0 + β1X1i + β2X2i + ui

Funcion de demanda de cerveza:
qi = β0 + β1 pbi + β2 mi + ui

Datos: cerveza.dta — 30 observaciones trimestrales. Variables: q (cantidad), pb (precio cerveza), pl (precio licor), pr (precio refresco), m (ingreso).

Componentes del modelo aplicado

SimboloVariableDescripcion
qiVariable dependienteCantidad demandada de cerveza (lo que queremos explicar)
pbiPrecio de la cervezaRegresor principal — relacion inversa esperada (β1 < 0)
miIngreso del consumidorRegresor de control — relacion directa esperada (β2 > 0)
β0InterceptoValor de q cuando pb = 0 y m = 0 (referencia teorica)
β1, β2PendientesParametros poblacionales desconocidos — derivadas parciales

Las pendientes como derivadas parciales

Los β son parametros poblacionales desconocidos que estimamos con MCO. Cada pendiente es exactamente una derivada parcial:

β1 = ∂q / ∂pb
Efecto precio
β2 = ∂q / ∂m
Efecto ingreso

Nota didactica: en las graficas usaremos regresion simple (un solo X) porque solo tenemos dos ejes para visualizar. Pero el modelo estimado con statsmodels es multiple (pb y m simultaneamente).

Para que sirve este modelo

  • Estimar la elasticidad-precio de la demanda de cerveza con datos reales
  • Controlar el efecto del ingreso para aislar el efecto puro del precio
  • Verificar si la cerveza es un bien normal o inferior segun el signo de β2
  • Base para modelos de demanda mas complejos (AIDS, sistemas de ecuaciones)
02 — Metodo de Estimacion

Minimos Cuadrados Ordinarios (MCO)

Para obtener los estimadores (β hat o β "sombrero") utilizamos informacion muestral. El objetivo es minimizar la distancia entre la realidad que estudiamos (Y) y la teoria (β0 + β1X1 + β2X2).

Idea geometrica — los residuos

Las lineas rojas verticales son los residuos ei. MCO minimiza la suma de sus cuadrados.

Recta: Y = — + — * X  |  SCR = —

Ecuacion 2 — El termino de error

De la Ecuacion 1 podemos despejar ui, que es la distancia entre la realidad Yi y la teoria:

ui = Yi − (β0 + β1X1i + β2X2i)

El objetivo de cualquier campo de las ciencias es minimizar esta distancia. De esto se trata MCO: encontrar los estimadores β̂ que minimizan estos residuos.

La formula de MCO

β̂ = (X'X)-1 X'Y

En la practica, MCO minimiza la Suma de Cuadrados de Residuos (SCR):

SCR = ∑ ui2 = ∑(Yi − Ŷi)2

Por que elevar al cuadrado?

1

Evita que residuos positivos y negativos se cancelen entre si.

2

Penaliza mas los errores grandes (efecto cuadratico).

3

Tiene solucion analitica unica — eficiente computacionalmente.

Teorema de Gauss-Markov: bajo los supuestos clasicos, MCO es el estimador lineal insesgado de minima varianza (BLUE: Best Linear Unbiased Estimator).

03 — El Termino de Error

Por que necesitamos ui?

El termino de error hace compatible la realidad con la teoria. Ninguna teoria explica perfectamente la realidad — ui es la distancia entre ambas.

Teoria vs Realidad

Recordemos que una teoria es un conjunto organizado de ideas que busca describir, entender o predecir un fenomeno. Las variables X que incluimos en el modelo hacen alusion a la teoria o al estado del arte sobre el problema de investigacion.

Que contiene ui

1

Variables omitidas

Factores que afectan la tarifa pero no incluimos: clima, trafico, tipo de pago. Sin embargo, ninguna teoria explica perfectamente la realidad.

2

Error de medicion

Imprecisiones en los datos: GPS redondeado, distancias aproximadas.

3

Aleatoriedad inherente

Comportamiento humano impredecible. Dos viajes identicos pueden tener tarifas diferentes.

4

Mala especificacion funcional

Si la relacion real es cuadratica pero modelamos como lineal, el error recoge esa no linealidad.

Del modelo teorico al estimado

Venimos de un modelo teorico (poblacional) con parametros desconocidos:

Yi = β0 + β1X1i + β2X2i + ui

MCO nos da los estimadores β̂ (beta hat) a partir de la muestra:

Ŷi = β̂0 + β̂1X1i + β̂2X2i

Error vs Residuo — diferencia clave

ConceptoSimboloObservable?Descripcion
Error poblacionaluiNoDistancia a la recta poblacional (desconocida)
Residuo muestraleiSiDistancia a la recta estimada — lo calculamos

En la practica: usamos los residuos ei para aproximar los errores ui. Son distintos pero en muestras grandes son muy similares.

Sin termino de error

Sin ui, el modelo afirmaria que conoce perfectamente Y. Eso seria estadisticamente incorrecto, imposible en ciencias sociales, y no nos permitiria hacer inferencia sobre la incertidumbre del modelo.

04 — Supuestos Clasicos

Supuestos del Termino de Error

Para que MCO sea BLUE (Gauss-Markov), el termino de error debe cumplir cinco supuestos. Violarlos tiene consecuencias distintas.

Supuesto 01 — Media cero

E[εi] = 0

El error promedio en la poblacion es cero. No hay sesgo sistematico. Si se viola: estimadores sesgados.

Supuesto 02 — Homocedasticidad

Var(εi) = σ2 (constante)

La varianza del error es la misma para todos los valores de X. Si se viola (heterocedasticidad): errores estandar incorrectos, inferencia invalida. Solucion: errores robustos.

Supuesto 03 — No autocorrelacion

Cov(εi, εj) = 0, i ≠ j

Los errores no estan correlacionados entre si. Frecuente en series de tiempo y datos espaciales. Solucion: errores de Newey-West o panel.

Supuesto 04 — Exogeneidad

Cov(Xk, εi) = 0

Las variables X no estan correlacionadas con el error. Es el supuesto MAS IMPORTANTE. Si se viola (endogeneidad): estimadores inconsistentes. Solucion: variables instrumentales.

Supuesto 05 — Normalidad (para inferencia)

εi ~ N(0, σ2)

Para hacer pruebas t y F exactas con muestras pequenas. Con muestras grandes (n > 100) el TCL garantiza normalidad asintótica — este supuesto es menos critico.

07 — Bondad de Ajuste

El coeficiente de determinacion R²

Mide la proporcion de la variacion total de Y que es explicada por el modelo. Va de 0 a 1.

Definicion y formula

R² = SCE / SCT = 1 - SCR / SCT

Interpretacion directa:

MAX

R² = 1.0 — El modelo explica el 100% de la variacion. Perfecto (sospechoso en datos reales).

MED

R² = 0.75 — El modelo explica el 75% de la variacion en la cantidad demandada.

MIN

R² = 0.0 — El modelo no explica nada. Equivalente a predecir siempre con la media.

R² ajustado — el que debes reportar

R²adj = 1 - (1 - R²) * (n-1)/(n-k-1)

El R² comun SIEMPRE sube al agregar variables, aunque sean irrelevantes. El R² ajustado penaliza por cada variable adicional — solo sube si la variable realmente mejora el ajuste.

08 — Inferencia Individual

Prueba t — Significancia Individual

Prueba si cada coeficiente es estadisticamente diferente de cero. Si no lo es, esa variable no aporta informacion al modelo.

La prueba de hipotesis

H0: βk = 0   (variable no tiene efecto)
H1: βk ≠ 0   (variable si tiene efecto)

El estadistico t se calcula como:

t = β̂k / se(β̂k)

Donde se es el error estandar del coeficiente.

Regla de decision

OK

p-valor < 0.05 → Rechazo H0. El coeficiente es significativo. La variable importa.

NO

p-valor ≥ 0.05 → No rechazo H0. No hay evidencia suficiente. Considerar eliminar la variable.

Significancia practica vs estadistica: un coeficiente puede ser estadisticamente significativo pero economicamente irrelevante si la magnitud es muy pequena. Siempre analizar ambas.

09 — Inferencia Conjunta

Prueba F — Significancia Global

Prueba si el modelo en su conjunto es estadisticamente significativo. Pregunta: sirve de algo incluir estas variables frente a predecir solo con la media?

La hipotesis conjunta

H0: β1 = β2 = ... = βk = 0
H1: al menos un βk ≠ 0

El estadistico F:

F = (SCE / k) / (SCR / (n - k - 1))
F = (R² / k) / ((1 - R²) / (n - k - 1))

Donde k = numero de regresores y n = numero de observaciones.

OK

F grande, p-valor < 0.05 → El modelo es globalmente significativo. Las X explican Y mejor que la media sola.

NO

F pequena, p-valor ≥ 0.05 → El modelo no aporta informacion. Revisar especificacion.

Relacion con R²: F y R² son equivalentes — un R² alto implica un F alto. Pero la prueba F da el valor-p formal para tomar la decision estadistica.

10 — Metricas de Pronostico

MAE, MSE y RMSE — Calidad del Pronostico

El R² mide ajuste global, pero estas metricas miden directamente que tan lejos estan las predicciones de los valores reales — en las mismas unidades de Y.

Metrica 01 — MAE

Error Absoluto Medio

MAE = (1/n) ∑ |Yi - Ŷi|

Interpretacion directa: el modelo se equivoca en promedio $3.21 en cada prediccion de tarifa.

VENTAJAS
  • Mismas unidades que Y (dolares)
  • Facil de explicar a no tecnicos
  • Robusto a valores extremos
DESVENTAJAS
  • No penaliza errores grandes
  • No diferenciable en cero
Metrica 02 — MSE

Error Cuadratico Medio

MSE = (1/n) ∑ (Yi - Ŷi)2

Interpretacion: promedio de los errores al cuadrado. Unidades: dolares2 — dificil de interpretar directamente.

VENTAJAS
  • Penaliza errores grandes mas
  • Diferenciable — util en optimizacion
  • Base matematica de MCO
DESVENTAJAS
  • Unidades al cuadrado
  • Muy sensible a outliers
Metrica 03 — RMSE

Raiz del Error Cuadratico Medio

RMSE = √MSE = √[(1/n) ∑ (Yi - Ŷi)2]

Interpretacion: el modelo se desvía en promedio $4.18 de la tarifa real, con mayor penalizacion a errores grandes.

VENTAJAS
  • Mismas unidades que Y
  • Penaliza errores grandes
  • La metrica estandar en ML
DESVENTAJAS
  • Sensible a outliers
  • Siempre RMSE ≥ MAE

12 — Bias-Varianza

Underfitting, Well-fit y Overfitting en Regresion

En regresion, el overfitting se ve como una curva que zigzaguea para pasar exactamente por cada punto de entrenamiento — aprende el ruido, no el patron. El grado del polinomio controla este balance, igual que K en KNN.

Underfit — Grado 1

Recta simple. No captura la curvatura de la relacion real. El modelo es demasiado simple — alto error en train y en test.

Grado 1
RMSE train: alto
RMSE test:  alto
Ambos altos — problema
Well-fit — Grado 3

Captura la curvatura sin memorizar el ruido. Balance optimo — la curva sigue el patron real.

Grado 3
RMSE train: bajo
RMSE test:  bajo
Brecha pequena — bien
Overfit — Grado 15

Curva que zigzaguea pasando por cada punto. Memoriza el ruido — RMSE train casi cero, RMSE test disparado.

Grado 15
RMSE train: casi 0
RMSE test:  muy alto
Brecha enorme — problema

Por que ocurre el overfitting

El modelo tiene demasiados grados de libertad respecto a los datos disponibles. En lugar de aprender el patron, aprende el ruido:

Datos reales:
y = sin(x) + RUIDO

Grado 1:  y = a·x + b
          ← No captura la curvatura

Grado 3:  y = a + b·x + c·x² + d·x³
          ← Captura el patron seno

Grado 15: y = a + b·x + ... + p·x¹⁵
          ← Memoriza el ruido tambien

Solucion: regularizacion Ridge

Ridge agrega una penalizacion al tamano de los coeficientes — equivalente al parametro C en SVM:

from sklearn.linear_model import Ridge

# Sin regularizacion — puede overfit
model = PolynomialFeatures(degree=15)

# Con Ridge — curva mas suave
ridge = Ridge(alpha=10.0)
# alpha grande = mas penalizacion = curva mas suave
# alpha = 0 equivale a MCO sin regularizacion

Resumen

Lo que aprendimos hoy

  • La regresion lineal multiple modela q en funcion de pb y m
  • MCO minimiza la SCR — bajo supuestos clasicos es BLUE (Gauss-Markov)
  • El error ε recoge variables omitidas, medicion y aleatoriedad
  • Los cinco supuestos del error garantizan validez de la inferencia
  • Cada βk se interpreta ceteris paribus — efecto parcial sobre q
  • R² mide proporcion explicada; R² ajustado penaliza variables inutiles
  • Prueba t: significancia individual de βpb y βm
  • Prueba F: significancia global — al menos un βk ≠ 0
  • MAE: error promedio en litros — robusto a valores atipicos
  • RMSE: penaliza errores grandes; RMSE ≥ MAE siempre
  • Sesgo-varianza: RMSE train vs RMSE test diagnostica underfitting y overfitting
  • statsmodels entrega coeficientes, t, p-valor, R² e intervalos de confianza
