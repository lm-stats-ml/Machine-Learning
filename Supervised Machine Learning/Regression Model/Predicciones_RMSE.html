01 — El Modelo

El modelo estimado con Train

Una vez entrenado sobre la muestra Train, el modelo queda definido por tres parametros fijos. Estos son los coeficientes que usaremos para predecir en Test.

Forma general del modelo de regresion lineal multiple:

q̂  =  β̂0  +  β̂1 · pb  +  β̂2 · m

Sustituyendo los valores estimados por statsmodels sobre Train:

q̂  =  57.9043  +  (−27.6258) · pb  +  (0.002555) · m
Parametro Variable Valor exacto (Python) Signo e interpretacion
β̂0 — Constante — 57.9043225341862 Nivel base de q cuando pb = 0 y m = 0
β̂1 pb −27.625790417248023 Negativo: a mayor pb, menor q (relacion inversa)
β̂2 m 0.0025553249022494343 Positivo: a mayor m, mayor q (relacion directa)
Importante: estos tres parametros no se recalculan. Fueron estimados una unica vez usando los datos de Train. La muestra Test nunca participo en su estimacion — por eso la evaluacion sobre Test es honesta.

04 — MAE y MSE

Calculando MAE y MSE a mano

Ambas metricas resumen todos los errores en un unico numero. La diferencia clave esta en como penalizan los errores grandes.

MAE — Error Absoluto Medio

MAE  =  1⁄n · ∑ |ei|  =  ∑|ei|⁄n

Suma de todos los errores absolutos, dividida entre n = 6:

|0.0828| + |3.2011| + |2.7292| + |0.5699| + |3.3059| + |4.0781|
= 0.0828 + 3.2011 + 2.7292 + 0.5699 + 3.3059 + 4.0781
= 13.9670
MAE = 13.9670 ÷ 6 = 2.3278
Interpretacion: en promedio, el modelo se equivoca en 2.33 unidades de q. Esta en las mismas unidades que q.

MSE — Error Cuadratico Medio

MSE  =  1⁄n · ∑ ei²  =  ∑ei²⁄n

Suma de cuadrados de errores, dividida entre n = 6:

0.0069 + 10.2470 + 7.4485 + 0.3248 + 10.9287 + 16.6308
 
= 45.5867
MSE = 45.5867 ÷ 6 = 7.5978
Interpretacion: el MSE esta en unidades al cuadrado de q, lo que lo hace dificil de interpretar directamente. Por eso se calcula el RMSE.
Por que el MSE es mayor que el MAE al cuadrado? Porque los errores grandes (como el de obs 15: 3.20, o el de obs 9: 4.08) quedan elevados al cuadrado y dominan la suma. El MSE castiga desproporcionadamente los errores grandes.
05 — RMSE

De MSE a RMSE

El problema del MSE es que esta en unidades al cuadrado. La solucion es tomar su raiz cuadrada: obtenemos el RMSE, que esta en las mismas unidades que q y es la metrica mas utilizada en regresion.

RMSE  =  √ MSE 
↓
RMSE  =  √ 7.5978 
↓
2.7564
unidades de q
Interpretacion practica: el modelo predice q con un error tipico de 2.76 unidades. Dado que los valores reales de q en el Test oscilan entre 46.8 y 57.8, este error representa aproximadamente el 5% del rango de la variable, lo que indica un ajuste razonable.

Las tres metricas: resumen comparativo

MAE

2.3278
Error promedio absoluto. Facil de comunicar. No penaliza especialmente los errores grandes.

MSE

7.5978
En unidades cuadradas de q. Penaliza errores grandes. Util para optimizacion matematica.

RMSE

2.7564
Raiz del MSE. Mismas unidades que q. Combina interpretabilidad y sensibilidad a errores grandes.
