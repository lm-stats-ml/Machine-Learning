01 — Concepto

Que es el AUC

AUC significa Area Under the Curve: el area bajo la curva ROC. Resume en un solo numero la capacidad discriminante del modelo sin depender del umbral elegido.

Interpretacion directa: AUC = 0.9684 significa que si tomamos al azar un comprador real y un no-comprador, el modelo asigna mayor probabilidad de compra al comprador en el 96.84% de los pares posibles. Solo en el 3.16% se equivoca en ese ranking.

A diferencia del accuracy, la sensibilidad o el F1, el AUC evalua el ranking de probabilidades en todos los umbrales posibles simultaneamente. Por eso es especialmente util cuando las clases estan desbalanceadas o cuando el umbral optimo no es evidente.

Por que es mejor que el accuracy

Cuando las clases estan desbalanceadas, un modelo que predice siempre "no compra" puede tener un 65% de accuracy sin aprender nada. El AUC no sufre este problema: compara probabilidades relativas entre pares de casos positivos y negativos.

Ventaja clave: independencia del umbral

El accuracy, recall, F1 y precision cambian cuando mueves el umbral de 0.5 a 0.3. El AUC permanece igual — resume la calidad discriminante del modelo en todos los umbrales posibles al mismo tiempo.

Regla practica: usa el AUC para comparar modelos entre si, y para reportar resultados en informes tecnicos. Usa recall, precision o F1 para decisiones operativas con un umbral especifico.

04 — Aplicacion

Cuando usar cada metrica

El AUC no reemplaza a las demas metricas; las complementa. La eleccion depende del objetivo del analisis y del costo de cada tipo de error.

Guia de seleccion por objetivo

SituacionMetrica recomendada
Comparar dos o mas modelos entre siAUC-ROC
Decidir a quien contactar (accion operativa)Recall o Precision (segun costo)
Reportar en informe tecnico o academicoAUC + F1
Clases muy desbalanceadasAUC (mas confiable que accuracy)
Evaluacion independiente del umbralAUC (unica metrica que lo logra)
Modelo de compra de tabletAUC (comparar) + Recall (operar)

Por que AUC es mas confiable con desbalance

Cuando una clase es mucho menos frecuente (ej: 10% compra, 90% no), el accuracy puede ser artificialmente alto: un modelo que siempre predice "no compra" alcanza 90% de accuracy sin aprender nada. El AUC no sufre esto porque compara probabilidades relativas, no conteos absolutos.

07 — Metrica

Recall — Sensibilidad

Recall mide que proporcion de los positivos reales detecta el modelo. Es critico cuando el costo de un falso negativo es alto (oportunidades perdidas, diagnosticos erroneos, fraude no detectado).

Formula
Recall = TPTP + FN = 2121 + 7 = 0.75
El denominador es el total de positivos reales (28 compradores en el test).
75%
Recall del modelo de tablet (umbral = 0.5)

21 de 28 compradores detectados. Los 7 FN representan oportunidades de venta perdidas. Con umbral optimo (0.280), el recall sube a 100% — se detectan los 28 compradores — a costa de reducir la especificidad de 96.2% a 86.5%.

Recomendacion: en marketing de producto, el costo de perder un comprador potencial (FN) suele superar al costo de contactar a alguien que no comprara (FP). Baja el umbral a 0.280 para maximizar el recall.

08 — Metrica

F1-Score — Media armonica

El F1-Score combina precision y recall en una sola cifra. Usa la media armonica, que penaliza fuertemente el desequilibrio entre las dos metricas.

Formula
F1 = 2 × Precision × RecallPrecision + Recall
F1 = 2 × (0.9130 × 0.75) / (0.9130 + 0.75) = 0.8235
0.8235
F1-Score del modelo de tablet (umbral = 0.5)

La precision (91.3%) supera al recall (75%), indicando que el modelo es conservador: cuando predice compra casi siempre acierta, pero se le escapan algunos compradores. La media aritmetica seria 0.830 — superior al F1 real (0.824), lo que muestra el valor de la media armonica para detectar desequilibrios.

Por que media armonica: si precision=1.0 y recall=0.01, la media aritmetica da 0.505 (parece aceptable). La media armonica da 0.02 (refleja la realidad: el modelo casi no detecta positivos). Penaliza el desequilibrio mucho mas sensiblemente.

La diferencia entre F1 y media aritmetica crece cuando precision y recall estan mas desiguales.

Cuando usar el F1

El F1 es la metrica de referencia cuando necesitas un unico numero que capture tanto la capacidad de deteccion (recall) como la exactitud de las alarmas (precision). Es especialmente util con clases desbalanceadas donde el accuracy puede ser engañoso.

Resumen: usa AUC para comparar modelos, F1 para reportar el balance con un umbral fijo, recall cuando los FN son criticos, y accuracy solo cuando las clases estan balanceadas.
09 — Aplicacion practica

Costos del error y que metrica usar

Elegir la metrica correcta no es una decision tecnica, es una decision de negocio. Depende de una sola pregunta: cual de los dos errores es mas costoso?

Escenario A — FN costoso

El modelo deja pasar un positivo real

No detecta cuando deberia. Genera oportunidades perdidas o riesgos no controlados.

Compra de tablet (tu modelo) FN = comprador potencial no identificado = venta perdida. El costo de un FP (contactar a alguien que no comprara) es menor.
Maximizar: Recall · Accion: bajar umbral
Escenario B — FP costoso

El modelo genera una alarma falsa

Clasifica como positivo a casos que son negativos. Genera costos operativos o financieros directos.

Aprobacion de credito bancario FP = prestar a un cliente insolvente = perdida real de capital. Un FN (rechazar un buen cliente) es tolerable.
Maximizar: Precision · Accion: subir umbral
