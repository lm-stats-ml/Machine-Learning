01 — Concepto

Que es la Regresion Logistica?

A pesar del nombre, es un modelo de clasificacion, no de regresion. Predice la probabilidad de que un evento ocurra.

Idea central

Toma una combinacion lineal de variables y la transforma mediante la funcion sigmoide para obtener un valor entre 0 y 1 — una probabilidad.

Pregunta tipica: Dado el genero, la edad y el salario estimado de una persona, cual es la probabilidad de que compre una tablet?

02 — Matematica

La funcion Sigmoide

Es el corazon del modelo. Convierte cualquier numero real en una probabilidad entre 0 y 1.

P(Compra=1) = 1 / (1 + e^-(b0 + b1*x))
Intercepto (b0) 0.0
Coeficiente (b1) 1.0

Propiedades:

— Siempre entre 0 y 1

— Forma de S (sigmoide)

— b0 desplaza la curva

— b1 controla la pendiente

03 — Interpretacion

Odds, Log-Odds y Coeficientes

Los coeficientes del logit se interpretan como cambios en el log-odds. Aqui explicamos cada concepto con el ejemplo de compra de tablets.

1

Probabilidad — lo que ya conoces

Es la chance de que algo pase, entre 0 y 1.

De 100 personas similares (mujer, 45 anos, $90k/ano), 70 compraron la tablet.
Probabilidad = 70/100 = 0.70 → "70% de chance de compra"
2

Odds — exitos vs fracasos

En lugar de cuantos compraron, pregunta cuantos compraron versus cuantos NO compraron.

Odds = 70 que SI compraron / 30 que NO compraron = 2.33
"Por cada persona que no compra, hay 2.33 que si compran"

Formula: Odds = p / (1-p) = 0.70 / 0.30 = 2.33

3

Log-Odds — por que el logit los necesita

Las odds van de 0 a infinito. El logaritmo las simetriza alrededor de 0, permitiendo una ecuacion lineal.

Log-Odds = ln(2.33) = 0.847

Ecuacion del modelo logit — tablets

log-odds = -12.784 + 0.334*Gender + 0.237*Age + 3.644e-05*Salary

El coeficiente de Age en lenguaje de compras

Si b_Age = 0.237:

Odds Ratio = e^0.237 = 1.267
Cada ano adicional de edad multiplica por 1.267 las chances de comprar la tablet (+26.7%).

04 — Como leer el Log-Odds

Como se interpreta el Log-Odds

El log-odds es el numero que el modelo predice directamente. Saber leerlo es clave para entender las predicciones de compra de tablets.

La regla de los tres casos

-

Log-odds negativo

Probabilidad menor al 50%. La persona probablemente NO compra la tablet.

Log-odds = -1.5 → Odds = 0.22 → P = 18%
0

Log-odds = 0

Exactamente 50/50. El modelo no puede decidir en ningun sentido.

Log-odds = 0.0 → Odds = 1.0 → P = 50%
+

Log-odds positivo

Probabilidad mayor al 50%. La persona probablemente SI compra la tablet.

Log-odds = +1.5 → Odds = 4.48 → P = 82%

De donde vienen estas cifras?

Importante: los valores -1.5, 0 y +1.5 son ejemplos pedagogicos con numeros redondos, no provienen del modelo de tablets. Solo ilustran los tres casos posibles del log-odds.

1

Log-Odds → Odds:   Odds = elog-odds

e-1.5 = 0.22  |  e0.0 = 1.00  |  e+1.5 = 4.48
2

Odds → Probabilidad:   P = Odds / (1 + Odds)

0.22 / 1.22 = 18%  |  1.00 / 2.00 = 50%  |  4.48 / 5.48 = 82%
√

Verificacion en Python

import math
for lo in [-1.5, 0.0, 1.5]:
    odds = math.exp(lo)
    p = odds / (1 + odds)
    print(f"lo={lo:+.1f} Odds={odds:.2f} P={p:.0%}")
# lo=-1.5 Odds=0.22 P=18%
# lo=+0.0 Odds=1.00 P=50%
# lo=+1.5 Odds=4.48 P=82%

Por que no hablar directo de probabilidades?

El modelo necesita una escala sin limites para hacer la ecuacion lineal:

Probabilidad:  0 ————————— 0.5 ————————— 1    (limitado)
Odds:             0 ————————— 1.0 ————————— ∞   (asimetrico)
Log-Odds:     -∞ ————————— 0.0 ————————— +∞ (ideal)

Ejemplo: coeficiente de Age = 0.237

Por cada ano adicional de edad, el log-odds sube 0.237.
Odds Ratio = e^0.237 = 1.267
Las personas mayores tienen 26.7% mas odds de comprar la tablet por cada ano extra de edad.

Truco practico: los coeficientes siempre se convierten a Odds Ratio (e^coef) o a efectos marginales (AME) para comunicarlos a directivos o equipos de marketing.

05 — Supuestos

Supuestos del Modelo

A diferencia de la regresion lineal, el logit tiene supuestos menos restrictivos — pero igualmente importantes.

01

Variable dependiente binaria

Y debe tomar valores 0 o 1. En nuestro caso: Purchased = 1 (compro la tablet), 0 (no compro).

02

Independencia de observaciones

Cada persona es una observacion independiente. Las 400 observaciones del dataset no deben estar correlacionadas entre si.

03

Linealidad en log-odds

La relacion entre cada variable continua (Age, EstimatedSalary) y el log-odds debe ser aproximadamente lineal.

04

Ausencia de multicolinealidad

Genero, Edad y Salario no deben estar altamente correlacionados. Verificar con VIF o matriz de correlacion.

05

Muestra suficiente

Regla practica: al menos 10 eventos por variable. Con 3 variables y 400 obs., el modelo esta bien dimensionado.

06

Sin separacion perfecta

Si una variable predice perfectamente la compra, los coeficientes divergen a infinito. Detectar con grafico de densidad.

06 — Implementacion

Logit en Python (statsmodels)

Pipeline completo: ajuste del modelo, calculo de Odds Ratios con intervalos de confianza y prueba de Wald.

Ajuste del modelo

import pandas as pd
import numpy as np
import statsmodels.api as sm

# Cargar datos (400 obs.)
df = pd.read_csv('tablet_purchases.csv')

# Variables: Gender (1=H, 0=M), Age, EstimatedSalary
X = df[['Gender', 'Age', 'EstimatedSalary']]
y = df['Purchased']

# Agregar intercepto (constante)
X = sm.add_constant(X)

# Ajustar modelo logit por MLE
logit_model = sm.Logit(y, X).fit()
print(logit_model.summary())

Odds Ratios con intervalos de confianza

# Odds Ratios = e^coeficiente
OR = np.exp(logit_model.params)
CI = np.exp(logit_model.conf_int())

resultado = pd.DataFrame({
  'OR': OR,
  'IC_lower': CI[0],
  'IC_upper': CI[1],
  'p-valor': logit_model.pvalues
})
print(resultado)

Prueba de Wald — inferencia global

El modelo logit no calcula directamente el estadistico F. La prueba de Wald evalua si los coeficientes de Age y EstimatedSalary son conjuntamente distintos de cero:

# Prueba de Wald conjunta
print(logit_model.wald_test(
    "Age = 0, EstimatedSalary = 0",
    scalar=True))
Wald test (chi2): statistic=85.864, p-value=2.26e-19, df=2
Conclusion: rechazamos H0. Age y/o EstimatedSalary son conjuntamente significativas.

Regla de lectura: OR > 1 = aumenta odds de compra. OR < 1 = reduce odds. IC que incluye el 1 = NO significativo.

Interpretacion de cada variable

Gender — OR = 1.396 (NO significativo, p = 0.274) Los hombres tienen 39.6% mas odds de comprar la tablet que las mujeres, controlando por edad y salario. Sin embargo, el intervalo de confianza [0.768, 2.540] incluye el valor 1, lo que indica que este efecto no es estadisticamente distinguible de cero. No se puede descartar la hipotesis de que el genero no tiene efecto en la compra.
Por que el valor critico es 1 y no 0?

El coeficiente reportado es el Odds Ratio (OR = eβ), no el coeficiente β directamente. El valor neutro — "sin efecto" — en escala de OR es 1, porque:

β = 0  →  OR = e0 = 1   (sin efecto)
β > 0  →  OR > 1           (aumenta el odds)
β < 0  →  OR < 1           (reduce el odds)

Para Gender: el IC [0.768, 2.540] contiene el 1, por lo que OR = 1 (ningun efecto) es un valor plausible. Es la misma logica que en regresion lineal, donde el IC de β no debe contener el 0 — solo que aqui la escala es multiplicativa, no aditiva.

Age — OR = 1.267 (*** altamente significativo, p = 2.61e-19)

Por cada ano adicional de edad, las odds de comprar la tablet aumentan un 26.7%, manteniendo constantes genero y salario. El IC [1.204, 1.335] esta completamente por encima de 1, confirmando el efecto positivo y significativo de la edad. Es la variable con mayor potencia estadistica del modelo (z = 8.984).

De donde sale el valor 1.267?
Por cada ano adicional de edad, el log-odds sube 0.237
Odds Ratio = e0.237 = 1.267
Por cada ano adicional de edad, las odds de compra aumentan en un 26.7%.

El coeficiente β = 0.237 opera en escala de log-odds. Para pasarlo a escala interpretable se aplica la exponencial: OR = eβ. El porcentaje de cambio en odds es entonces (OR − 1) × 100 = (1.267 − 1) × 100 = 26.7%.

EstimatedSalary — OR = 1.000036 por $ (*** altamente significativo, p = 2.77e-11) El efecto unitario es muy pequeno porque el salario se mide en dolares individuales. Para interpretarlo de forma practica: por cada $10,000 adicionales de salario, las odds de compra aumentan un 44%. El IC [1.000026, 1.000047] confirma significancia positiva.
De donde viene el 44%?

El OR por $10,000 se calcula escalando el coeficiente β = 3.644×10−5:

OR = e(3.644×10−5 × 10,000) = e0.3644 = 1.4396
Aumento en odds = OR − 1 = 1.4396 − 1 = 0.4396 ≈ 44%

El 44% no es el exponente 0.3644 directamente — eso daria un error del 7.7%. El porcentaje correcto siempre es (eβ×escala − 1) × 100.

08 — Efectos Marginales

Efectos Marginales Promedio (AME)

La forma mas intuitiva de interpretar el logit. Expresan el efecto de cada variable directamente en puntos porcentuales de probabilidad de compra.

Tabla de efectos marginales (dy/dx)

Variabledy/dxStd ErrzP>|z|IC 95%Sig.
Gender 0.0368 0.034 1.099 0.272 [-0.029, 0.103] n.s.
Age 0.0262 0.001 18.674 0.000 [0.023, 0.029] ***
EstimatedSalary 4.022e-06 4.55e-07 8.840 0.000 [3.13e-06, 4.91e-06] ***

Interpretacion de cada AME

Gender — AME = +3.68 pp (NO significativo, p = 0.272) En promedio, ser hombre aumenta 3.68 puntos porcentuales la probabilidad de comprar la tablet. Sin embargo, el IC [-0.029, 0.103] cruza el cero — no podemos descartar que el efecto real sea nulo o incluso negativo.
Age — AME = +2.62 pp por ano (*** altamente significativo) Cada ano adicional de edad aumenta en promedio 2.62 puntos porcentuales la probabilidad de compra. Con z = 18.674 y IC = [0.023, 0.029], este es el efecto mas precisamente estimado del modelo. Ejemplo: un cliente de 50 anos tiene, en promedio, 26.2 pp mas de probabilidad de compra que uno de 40.
EstimatedSalary — AME = 4.022e-06 pp por $ (*** altamente significativo) Por cada dolar adicional de salario, la probabilidad de compra aumenta 0.0004%. Para interpretarlo de forma practica: por cada $10,000 adicionales, la probabilidad de compra sube en promedio 4.02 puntos porcentuales.

Codigo en Python

# statsmodels calcula AME nativamente
marginal_effects = logit_model.get_margeff()
print(marginal_effects.summary())

# Resultado (dydx = dy/dx = AME):
# Gender: dy/dx = 0.0368 (n.s.)
# Age: dy/dx = 0.0262 ***
# EstimatedSalary: dy/dx = 4.022e-06 ***
# (equivale a +4.02 pp por cada $10,000)

# Calculo manual del factor de escala:
import numpy as np
probs = logit_model.predict()
scale = np.mean(probs * (1 - probs))
print(f"Factor de escala: {scale:.4f}")
# AME = coeficiente * factor de escala
for name, coef in logit_model.params.items():
    print(f"{name}: AME = {coef*scale:+.4f}")

AME vs OR: el AME es mas facil de comunicar a audiencias no tecnicas ("cada ano extra de edad sube 2.6 pp la probabilidad"), mientras que el OR es preferido en publicaciones clinicas o epidemiologicas.

Resumen

Lo que aprendimos hoy

  • Logit predice probabilidades de compra (0 a 1), no valores continuos
  • La funcion sigmoide transforma log-odds en probabilidades; los valores -1.5, 0 y +1.5 son ejemplos pedagogicos calculados como e^(log-odds) y Odds/(1+Odds)
  • Los coeficientes se interpretan como cambios en log-odds por unidad de cada variable
  • Odds Ratio (e^coef): Age OR=1.267 (+26.7% odds/ano), Salary OR=1.44 por $10k — ambos altamente significativos (p<0.001)
  • Gender OR=1.396 pero NO significativo (p=0.274); su IC [0.768, 2.540] incluye el 1
  • Prueba de Wald: chi2=85.86, p=2.26e-19 — Age y Salary son conjuntamente significativas
  • Efectos marginales AME: Age +2.62 pp/ano, Salary +4.02 pp/$10k, Gender +3.68 pp (n.s.)
  • Pseudo R² McFadden = 0.4711 — ajuste excelente del modelo (umbral de referencia: >0.40)
